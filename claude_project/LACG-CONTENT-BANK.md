## 3. TAG BANK — exact chip texts

Copy a tag EXACTLY as written here.

| Tag | Use it when the move... |
|---|---|
| Sacrifice | gives up something real to win more |
| Exchange Sacrifice | gives up a strong asset for a weaker one on purpose, for position |
| Gambit | gives something small early to seize the initiative |
| Poisoned Pawn | offers bait that looks free but costs the taker the game |
| Trap | sets up a mistake the opponent is invited to make |
| Swindle | escapes a lost position through a trick |
| Fork | creates two threats at once; only one can be answered |
| Pin | freezes a piece: moving it would expose something worse |
| Skewer | attacks the big piece so the one behind it falls |
| Discovered Attack | one move uncovers a second, hidden threat |
| Double Attack | two separate threats in one move |
| Deflection | pulls a defender away from what it protects |
| Decoy | lures a piece onto a bad square |
| Overloaded Piece | one defender has too many jobs |
| Hanging Piece | something valuable left undefended |
| Zwischenzug | an unexpected in-between move before the expected reply |
| Zugzwang | any move, even silence, makes it worse |
| Tempo | forces a reaction and gains time |
| Quiet Move | a calm, small move with a deadly point |
| Only Move | the single move that does not lose |
| Prophylaxis | stops the opponent's plan before it starts |
| Counterattack | answers a threat with a bigger threat |
| Desperado | a doomed piece grabs what it can before it falls |
| Fortress | an unbreakable defensive setup |
| Opening Prep | a move clearly prepared before the game |
| Time Pressure | the clock forces a rushed decision |
| Back Rank | the king's own guards become its trap |
| Weak Square | a hole in the position the opponent can occupy |
| Outpost | a safe, strong position that cannot be chased away |
| Mating Net | the walls close in; mate is coming |
| Perpetual Check | endless threats to force a draw |
| Stalemate Trick | a losing side forces a draw from nothing |
| Simplification | trades down to an easily won ending |
| Endgame Technique | converts an advantage cleanly |
